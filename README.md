# ספריית מדריכי בינה מלאכותית למורה — אהרון הרואה בנות

אתר סטטי: עשרה מדריכים מעשיים לשימוש מושכל בבינה מלאכותית בהוראה ביסודי, עם חיפוש בעברית, מאגר פרומפטים, מחולל פרומפטים, עשרה כלי עזר להפעלה ישירה, ו-PDF להורדה לכל מדריך.

**האתר החי:** https://sashka2022.github.io/aharon-ai-library/

## מה יש כאן
- `index.html` — דף האתר. הניווט מבוסס `#`: `#g01` עד `#g10`, `#prompts`, `#generator`, `#about`.
- `assets/guides.js` — תוכן עשרת המדריכים, נוצר אוטומטית ממקורות החוברות.
- `assets/app.js` — חיפוש, סינון, העתקת פרומפטים, מחולל פרומפטים, כלי העזר החיים, סימון "קראתי" והגדלת טקסט.
- `assets/guide.css`, `assets/site.css`, `assets/fonts/` — עיצוב והגופן Heebo (רישיון SIL OFL).
- `pdf/` — עשר החוברות להדפסה ולהורדה.

אין שרת, אין מסד נתונים ואין תהליך בנייה. אפשר גם להוריד את התיקייה ולפתוח את `index.html` מקומית.

## פרטיות
האתר אינו אוסף מידע ואינו שולח דבר לשרת. סימוני "קראתי", גודל הטקסט וטיוטת המחולל נשמרים רק בדפדפן של המשתמשת. אין בחומרים שמות תלמידות, תצלומים, הקלטות או נתונים אישיים; כל הדוגמאות סינתטיות.

## הערות על התוכן
- המידע על כלי ה-AI אומת מול תיעוד רשמי ב-24.11.2026 ומסומן "אומת בתיעוד בלבד". כלים ותנאים משתנים — כדאי לבדוק לפני שימוש.
- במדריכים ה-AI משמש את המורה לתכנון ולהכנה. כל שימוש של תלמידות מותנה בהנחיות משרד החינוך העדכניות ובמדיניות בית הספר.
- העיצוב מוצע ולא אושר רשמית. אין באתר לוגו של בית הספר.
